# 写实人物

默认人物参考了录屏里的生活 Vlog 质感，以原创短发人物、暖侧光、自然皮肤和粉色棉衬衫为基础。皮肤、发丝和衣料细节保留在带透明通道的 WebP 里。直播页面本地运行，可用半身或近景镜头。

面部网格有鼻梁、脸颊和头颈深度，支持轻微偏头、视线变化、呼吸和眨眼。音频能量与频谱驱动张口、圆唇和横展三组口型，喜悦情绪带动微笑。画面适合正面机位和小角度，侧脸、背面和全身动作可以通过带骨骼的 VRM / GLB 形象实现。

## 人物主体

把以下地址添加为 OBS 浏览器源，竖屏设置为 1080 × 1920，横屏设置为 1920 × 1080。

```text
http://127.0.0.1:8000/?obs=1&background=transparent&subject=1
```

把自己的背景源放在人物源下方。添加 `&camera=close` 使用近景，添加 `&quality=low` 使用 30 FPS。去掉 `subject=1` 可同时显示字幕和礼物特效。需要开启声音时，可以通过 OBS「交互」点击「开启声音」。

## 自制素材

`static/portraits/daylight/` 包含透明底图、表情纹理图集和网格配置。浏览器直接加载这些已生成的素材。制作其他人物时，准备同一人物、固定光照和机位的透明闭口正脸、张口和闭眼图。还可提供圆唇、横展和微笑三张图。使用 Google 的 Face Landmarker 材料在本机对齐和烘焙。[Face Landmarker 文档](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker?tab=Python)

```bash
uv run --no-project --python 3.12 --with mediapipe==0.10.32 --with pillow --with scipy \
  python tools/bake_portrait.py neutral.png open.png blink.png face_landmarker.task static/portraits/my-host \
  --round round.png --wide wide.png --smile smile.png
```

`face_landmarker.task` 使用 [MediaPipe 官方模型](https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task)。将 `config/avatar3d.json` 中的 `portrait.manifest` 指向 `/static/portraits/my-host/rig.json`，保存后刷新。配置了原有 `url` 时优先载入 VRM / GLB，可在页面切回写实人物。
